*截至 2026-10-28。所有数字均出自 `benchmarks/results/` 下本轮新生成的结果文件（各文件记录了 commit、未提交改动的哈希、
方案文件的 sha256 与种子）。每项新评估都先写方案和判定标准，再用未使用过的种子运行；未通过的标准如实报告，并按方案预先写好的

## 一句话结论

本轮补充了压力测试、输出限制说明和界值评估，进一步明确了统计适用边界，也发现了样本级共有扰动、零假设尾部校准和区间覆盖
方面的限制。独立阳性案例仍未完成：GSE218269 用作者 bigWig 和从原始 reads 重新处理两次均不满足深度标准 S3（重新处理后
精确计数中位数 85 < 100），按方案最终定为"无法评估"，open item 1 仍开放。"额外生物学价值"尚未获得确认性证据。随后做了一次预先写明、标为探索性的分析
（B4）：检出广泛的形状差异（`shape_any` 40 %），并有小幅的预测增益（30 min 交叉验证 R² 增加 0.0056）；预期的上游变化
未得到支持（`shift` 无显著区域，方向比例无法评价；质心区间跨零），区域级变化类型尚未确定。这些不作为确认；诊断性补充
分析（B5）正在进行。A2 的评估代码在运行前已修复染色体 bootstrap 的跨折重复问题（修正说明 B3）。

## 2. 统计适用边界：汇总零分布的压力测试

结果：`benchmarks/results/stress_v1`；方案：`docs/PROFILESHAPE_STRESS_PROTOCOL.md`；种子 9 600 000+，每单元格 100 次，
600 个区域，2 vs 2 与 3 vs 3。判定沿用校准研究：EXCEEDS = 平均 FDP 的 95 % 区间整体高于 0.05。

**24 个单元格中，2 个是全部区域改变的场景（没有真零假设，只评价功效）；其余 22 个可评价错误率的单元格中，1 个明确超标
（2 vs 2，每个重复各带 sd 20 bp 的样本级整体平移），21 个未发现明确超标。"ok" 的含义是没有统计上明确的超标，不是证明
FDR ≤ 0.05。**

| 因素 | 水平 | 最差的整表 FDP（检验，设计） | 判定 |
|---|---|---|---|
| 高比例改变 | 70 % / 90 % / 100 % | 0.035（shape_kernel，2v2，70 %） | ok |
| 全部同方向平移 | 50 % / 90 % | 0.048（shape_kernel，2v2，50 %） | ok |
| 样本级整体平移 | sd 5 / 10 / 20 bp | **0.080 [0.051, 0.109]**（shape_kernel，2v2，20 bp）；shape_any 0.068 | **EXCEEDS** |
| 部分混杂的批次 | 未声明 / 声明并在批次内置换 | 0.048 | ok |
| 真实多峰形状（GSE112560 模板） | — | 0.046 | ok |
| 窗口三重重叠（0 / +150 / +300 bp） | — | 0.050 | ok |

- 样本级平移 sd ≤ 10 bp，或 3 vs 3，未发现明确超标，但不等于在名义水平内：例如 sd 20 bp、3 vs 3 的 `shape_any` 为
  0.053 [0.032, 0.074]。
- 与酵母的关系：这是一种能产生类似超额的**候选机制**，与真实数据中"样本结构与超额相关"相容，但尚未确认。我们自己的数据
  还说明酵母的重复差异**不是整体平移**：consistency_v2 中各酵母组重复间的偏移占 profile 的 2.6–37 %，平移等价量却只有
  1.2–3.7 bp，远小于模拟的 sd 20 bp。因此更合适的表述是"样本级共有的形状扰动"这一大类，具体形式未知。
- 不属于判定标准但需说明：90 % 区域改变时，**未改变区域**的 p < 0.01 比例达 0.069（2v2，名义 0.01）。整表 FDP 仍低，是因为
  列表由真实变化主导；单区域层面的零假设校准此时不成立，高比例改变下的边界仍需研究。
- 两点均已写入 `docs/PROFILESHAPE_V3_REVIEW.md` §7 第 9 条与用户指南；本轮未为此修改方法。

## 4. 创新性定位与 RegCFinder

依据：Weiß & Friedel 2023, *Bioinform Adv* 3:vbad085（论文）与其 `amss` 模块源码（`quantify_curves_efficient.R`）。

| 方面 | RegCFinder | ProfileShape |
|---|---|---|
| 回答的问题 | 窗口内**哪一段**的相对密度变了 | 区域形状**是否**有重复支持的变化；对部分区域给出满足拟合一致性条件的描述性位移（不是经过验证的变化类型分类） |
| 定位 | 有（子区段坐标） | 无 |
| 片段搜索如何使用重复 | 先平均，**不使用重复间变异** | 重复是推断单位 |
| 随机化的零假设 | 打乱位置顺序（源码 `sample(df[,4])`） | 置换重复标签，跨区域汇总 |
| 选择偏差 | 片段由数据选出，再用同一份数据做 DEXSeq 检验 | 区域预先给定、与标签无关 |
| 计数模型 | 有（DEXSeq 负二项） | 无（归一化信号；深度只作诊断） |
| 校准证据 | 未报告模拟或 FDR 校准 | 大量模拟与半真实验证；已发现的限制见 §2 |

- 文献文档 §5 重写："Not new" 中加入 RegCFinder（区域内再分布 + 定位）；贡献表述为：在 2–3 个重复下，通过标签不变的稳定项、
  按协变量分层的跨区域汇总置换零分布与组合检验，对预定义区域做空间再分布筛查；并明确 2 vs 2 的推断依赖跨区域假设。
- manuscript plan 已重写（旧版 v2.4 数字已作废），包含证据对照表与消融实验清单。
- 推断（未实测）：RegCFinder 在零假设下的窗口级 FDP 可能偏高。比较方案已写，按决定暂缓。

## 5. 组内一致性模块

方案：`docs/PROFILESHAPE_CONSISTENCY_EVALUATION.md`；结果：`benchmarks/results/consistency_v2`（v1 发现实现缺陷后保留原样，
修正写在修正说明 A1，v2 用新种子重跑）。数据：11 个数据集、7 种 assay（MNase、ATAC、TF ChIP、TF CUT&RUN、PRO-seq、
H3K27ac 与 H3K4me3 的 ChIP-seq 和 CUT&RUN），5 类区域（ATG、+1 核小体、consensus peak、合并信号 summit、TSS）。

| 标准 | 内容 | 结果 |
|---|---|---|
| K1–K3 | 零假设下的标记率与 p 值校准（含一个样本为 30 % 深度） | 通过：模拟每单元格 ≤ 0.04；真实噪声每组 ≤ 2/20；P(p<0.01) 0.009–0.013 |
| K4 | bp 区间覆盖率 ≥ 0.90 | **未通过**：合并 0.94–0.95，但 31 个真实噪声单元格中 2 个为 0.85 |
| K5 | 已知平移的大小恢复 | 通过：+20 / +50 bp 估为 +20.0 / +51.0 |
| K6–K8 | F₂₀ 超出量、拆分 π̂₁ 在零假设下接近 0；不高估 | 通过（模拟中 π̂₁ 0.21 对真值 0.20；真实噪声上 0.05–0.32） |
| K9 | 灵敏度 | 通过：单个重复整体平移 20 bp 或展宽 ×1.3 在所有数据集检出；只 10 % 区域偏移时 ≤ 0.12 |
| K10 | 被标记的拆分在真实零假设中是否更多检出 | **无法评估**：62 个新拆分中 `shape_any` 一个检出都没有，包括 4 个被标记的拆分 |

- v1 的缺陷：近乎空的窗口除以极小的 mass，数值达约 10¹⁶，使 ATAC 与 k27ac_chip 的拆分 z 全部为 ±1。修正：每个样本的 mass
  须达到其中位数的 10 %。另：不等分拆分（如 2|4）中浅样本会推高 π̂₁，改为只对等分拆分计算。
- 按单个样本计算的"不一致区域比例"（1 vs 其余的 π̂₁）已撤销：零假设下有一个浅样本时就达 0.38，受深度影响。
- 真实数据（描述性）：30 组中 17 组有标记，但很多偏移只占 profile 的 1–3 %、位移 < 1 bp——标记是相对组内其他样本而言的，
  不等于有实际影响。

## 6. 容忍界值框架

用户在分析前设定可接受的差异（偏移 %、平移 bp），工具给出"在界值以内 / 超出界值 / 无法判断"，并始终报告上限。
方案：`docs/PROFILESHAPE_MARGIN_EVALUATION.md`；结果：`benchmarks/results/margin_v1`（模拟 8100 次，半真实 5400 次）。

| 量 | M1（模拟，误判为"以内"） | M2（真实噪声） | 区间覆盖率（M3 / M4） | 按方案的后果 |
|---|---|---|---|---|
| 平移（bp） | 通过（最差 0.08，位于界值处） | **通过**（0 组超标） | 未通过：模拟最差单元格 0.82；真实噪声 0.23–0.92 | 保留判定（适用范围见下）；区间标为未通过覆盖检查 |
| stretch（%） | 通过 | **未通过**（24 组超标；真实形状上估计为真值的 0.25–1.26 倍） | 未通过 | **撤销判定**，只给描述性估计 |
| 偏移（%） | 通过 | 未评估（真实形状上真值未知） | 未通过：上限覆盖 0.901 < 0.93 | 保留判定（仅模拟验证）；区间标注 |

- 区间覆盖差的原因：线性估计有几个百分点的偏差，而数千个区域使区间极窄。
- 平移判定的证据范围：在已测试的正向位移和指定界值（模拟 10 bp；半真实 max(10 bp, bin)）下，"误判为以内"的比例满足预设的
  经验标准（界值处允许 ≤ 0.10 和 ≤ 3/20）。其他界值、负向位移、紧邻界值的效应，以及"误判为超出"均未得到同等验证；
  区间欠覆盖时，界值附近的小偏差也可能改变结论。
- "有多少比例的区域不一致"类界值不提供（π̂₁ 与 F_δ 不够准）。
- 按 assay 的预设（`assay: atac | mnase | tf_chip | tf_cutrun | histone_narrow | histone_broad | proseq`）只设窗口参数，不设界值。

## 7. 独立阳性案例

方案：`docs/PROFILESHAPE_POSITIVE_CASE_PROTOCOL.md`（第一阶段选择标准 → 第二阶段数据集预测 → 修正说明 B1、B2）。

**选择。** 在 GEO 中筛查 481 个系列（暂停释放/延伸扰动与 H3K4me3 宽度扰动；要求 ≥ 3 个重复、独立读出、未用于开发、深度足够）。

| 排名 | 数据 | 结果 |
|---|---|---|
| 1 | GSE218269：CDK7 抑制 30 min，Pol II MNase-ChIP-seq 3 vs 3；读出 TT-seq | 主案例 |
| 2 | GSE152595：COMPASS 突变，H3K4me3 ChIP-seq 4 vs 4 | **撤出**：原文（Sze et al. 2020）报告的是覆盖度下降，不是 domain 收窄，不满足 S1 |
| 3 | GSE245600：CDK-TCIP1，Pol II ChIP 3 vs 3 | 备选，未用 |

**下载前写定的预测**（依据 Velychko et al. 2024 Fig. 3B：pause 区 Pol II 减少，TSS 上游约 30 bp 处增加）：

- P1：`shape_any` 检出 ≥ 20 % 的区域；
- P2：`shift` 显著区域中 ≥ 80 % 方向朝上游；
- P3：聚合质心向上游移动；
- A2（主终点）：在控制 Pol II 总量、深度、基线 TT-seq、基因长度、峰宽后，加入形状统计量能否提高对 TT-seq 变化
  （30 min，log2FC）的交叉验证 R²（按染色体分折，染色体 bootstrap 95 % 下限 > 0）。

**进展。**

1. 用作者处理好的 bigWig：深度不满足 S3（估计中位数 58 个片段/区域/样本，要求 ≥ 100），原因是作者只保留了 < 70 bp 的片段。
   按方案报告为"无法评估"（`benchmarks/results/positive_case_gse218269`，修正说明 B1）。A1、A2 未计算。
2. 修正说明 B2（下载 reads 之前写定）：从原始 reads 重新比对（bowtie2，GRCh38），片段放宽到 20–120 bp，用 BAM 的精确
   计数检查 S3；若仍不满足，本案例最终定为"无法评估"。预测保持不变；更宽的片段会模糊 PIC 与 pause 的区分，对 P2 不利，
   照常接受。
3. 结果（B2 的结论）：6 个样本比对率 86.8–94.6 %，重复率 4.6–7.0 %。核心窗口（TSS ± 500 bp）内 20–120 bp 片段的精确
   计数，每个样本的区域中位数为 DMSO 86 / 95 / 84，CDK7i 77 / 82 / 93，6 个样本中位数 85 < 100。**S3 不满足，按 B2 最终
   定为"无法评估"**（`benchmarks/results/positive_case_gse218269_bam`），不放宽阈值或窗口。一致性模块标出 DMSO_1（偏移为
   同组的 4.7 倍，占聚合 profile 的 4.2 %）和 CDK7i_1（2.7 倍，3.3 %）。
4. 探索性分析（修正说明 B4，运行前写定：只关掉 S3 门槛，其余不变；不计为确认，也不用于挑选替代数据集）：
   `benchmarks/results/positive_case_gse218269_bam_exploratory`。

   | 项目 | 结果 |
   |---|---|
   | P1 `shape_any` 检出比例 ≥ 0.20 | 0.400（3148 / 7865）；`shape_kernel` 3720 个 |
   | P2 `shift` 显著区域中朝上游 ≥ 0.80 | `shift` 显著 0 个（p < 0.01 的比例 4.6 %）：比例没有分母，**无法评价方向**；预设标准未达到，但不能据此说明不存在上游变化 |
   | P3 聚合质心向上游 | +5.6 bp [−1.6, +12.9]：区间跨零，**不确定**（不是证实反向移动）；预设标准未达到 |
   | 聚合形状 | 聚合曲线呈变窄趋势：IQR 宽度 −30 bp [−41, −20]，不对称度 −0.15 [−0.19, −0.11]；逐区域 `mad_width` 检验 FDR 下 0 个检出（p < 0.01 占 2.4 %）——B5 D2 显示该检验在此深度下几乎没有功效，0 个检出不提供信息 |
   | A2 | 基线 R² 很低（30 min 0.034）。增益 30 min +0.0056 [+0.0025, +0.0085]，60 min +0.0048 [+0.0021, +0.0074]，15 min +0.0005 [−0.0007, +0.0016]（跨零）；signed shift 的标准化系数 −0.027（预期为正），核检验 +0.003 |

   解读：检测到广泛的形状差异，聚合曲线呈变窄趋势，但区域级变化类型尚未确定（聚合变窄不说明 3148 个检出区域都变窄；
   `shift` 不显著也不能排除平移）；预期的上游变化未得到支持。A2 在 30 和 60 min 有小幅正增益——不是确认性成功，也不说明
   机制；增益来自哪个形状指标需要消融（B5 D1）才能判断，系数反号影响机制解释，但不自动否定增益。片段长度中位数相近
   （64–68 bp）不足以排除 MNase 消化或背景差异；20–120 bp 是片段长度范围，不等于有效空间分辨率（midpoint 的位置精度远
   高于片段长度）——片段范围与信号表示只列为待验证因素（B5 D3）。B2 在运行前已写明更宽片段可能对 P2 不利。

   重复支持与可检出性；D3 同一 BAM 上 3 种片段范围 × 2 种表示，以及每组去掉一个重复的 6 种组合。
   **B5 结果**（`benchmarks/results/positive_case_gse218269_diag`；全部探索性；B4 的 A1 完全复现）：
